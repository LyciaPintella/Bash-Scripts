Split a long command into multiple lines:
Use a backslash (\) at the end of each line to tell Bash the command continues:

Copy code
echo "This is a very long line that I \
want to split across multiple \
lines for readability."
Output: This is a very long line that I want to split across multiple lines for readability.

If you want to paste multiple commands into a Bash terminal (like Konsole) and have them all execute at once, there are several safe and reliable ways to do it.

1. Separate Commands with ;
Runs commands sequentially, regardless of success or failure.

command1; command2; command3
Example: cd /tmp; mkdir testdir; echo "Done"

2. Use && for Conditional Execution
Runs the next command only if the previous one succeeds (exit code 0).

command1 && command2 && command3
Example: gcc main.c -o main && ./main && echo "Program finished"

3. Use { ...; } for a Block
Executes multiple commands as a single block in the current shell.

{ command1; command2; command3; }
Example: { cd /tmp; ls; echo "Listed /tmp"; }

Note: Each command inside must end with ; or a newline.

4. Use a Here-Document for Multi-Line Paste
If you want to paste multi-line scripts directly:

bash <<'EOF'
echo "Step 1"
pwd
ls -l
EOF

Everything between EOF markers will run as one script.

5. Paste into Konsole Without Premature Execution
In Konsole, sometimes pasting multiple lines executes them one-by-one immediately.
To avoid this:

Option A: Paste into a text editor first, join with ; or &&, then paste into terminal.
Option B: Use Shift+Ctrl+V (Paste Without Formatting) to avoid accidental line-by-line execution.
Option C: Start a subshell and paste inside:
bash
# paste commands here
exit

✅ Recommendation:
If you want all commands to run in one go when pasted, join them with ; or wrap them in { ...; }.
If you want stop-on-error behavior, use &&.
